# 本地测试与 Git 推送常用命令

1. 运行所有相关 TDD 测试套件：
flutter test test/features/ux_team_experience_test.dart test/features/remote_team_sync_test.dart test/features/team_registration_and_navigation_test.dart

2. 预发布全量检查：
.\validate_before_push.bat

3. 提交与推送至 GitHub：
git add .
git commit -m "feat_remote_team_ux_optimization"
git push
