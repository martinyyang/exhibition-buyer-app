================================================================================
🆘 故障排查
================================================================================

问题 1: Android SDK 检查失败
→ 重启终端，确保环境变量生效
→ 手动设置: export ANDROID_HOME="C:\Users\...\Android\Sdk"
→ 查看: docs/ANDROID_SDK_SETUP.md

问题 2: 模拟器启动失败
→ 检查可用模拟器: emulator -list-avds
→ 创建新模拟器: 见 docs/emulator_setup.md
→ 启用虚拟化: BIOS 设置

问题 3: APK 构建失败
→ 清理缓存: flutter clean && flutter pub get
→ 重新构建: flutter build apk --release
→ 查看日志: build/*.log

问题 4: 测试失败
→ 查看详细日志: logcat_*.log
→ 查看测试报告: test_report_*.txt
→ 参考故障排查: docs/EMULATOR_TEST_GUIDE.md
