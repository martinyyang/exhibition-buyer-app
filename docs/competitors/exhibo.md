# Exhibo - AI-Powered Trade Show Assistant

**网站**：https://exhibopro.com  
**平台**：iOS (App Store)，Android (Coming Soon)  
**发现日期**：2026-08-07  
**状态**：Active，唯一找到的为买方设计的展会 App

---

## 产品定位

**Slogan**: "Document smarter, not harder"  
**核心价值**：AI 驱动的展会采购助手，帮助采购团队记录供应商、生成报告、团队协作

**目标用户**：
- 家具/五金：CIFF, Interzum, KIFF
- 电子/科技：CES, Global Sources, Canton Fair (广交会)
- 食品/饮料：SIAL, Anuga, Gulfood
- 时尚/纺织：Intertextile, Premiere Vision

---

## 核心功能

### 1. 照片记录
- 拍摄产品和展位照片
- 将照片附加到供应商记录和发现(Findings)

### 2. 团队协作
- 团队成员共享供应商信息
- 实时更新发现和任务
- 支持团队邀请

### 3. AI 报告生成（核心差异化）
- **每日报告** + **最终报告**
- 供应商分析
- 价格对比
- 可执行建议(Actionable Recommendations)

### 4. 数据导出
- Excel 格式
- PDF 格式
- 导出内容：供应商列表、发现、完整报告

### 5. 多语言支持
- 支持 3 种语言（未明确具体语言）

---

## 工作流程

1. **设置展会** → 邀请团队成员
2. **记录供应商** → 拍照 + 添加发现(Findings)
3. **生成洞察** → AI 分析 + 报告导出

## 优劣势分析

### Exhibo 的优势
1. **AI 报告生成** - 自动化分析和建议（我们没有）
2. **数据导出** - Excel/PDF 适合采购流程下游（我们没有）
3. **多行业验证** - 明确列出家具/电子/食品/时尚等垂直场景
4. **移动 App** - 原生体验（虽然我们是 Web 优先）

### Exhibo 的劣势（我们的机会）
1. **标注精度不明** - 没有提及精准定位功能（我们的核心优势）
2. **价格转换** - 只提到"对比"，未提及公式计算器
3. **中国市场** - 未提及网络优化（广交会提了，但技术层面无说明）
4. **开源透明** - 闭源产品（我们可以走开源 + 自部署路线）

### 我们的差异化机会

**短期竞争点**：
- **精准标注** - 十字准星是独特体验，Exhibo 未强调
- **公式计算器** - 实时价格转换（USD → RMB，FOB → CIF 等）
- **中国市场** - 网络稳定性 + 本地化体验

**长期补强方向**：
- 考虑 AI 报告生成（LLM 总结采购建议）
- 数据导出功能（Excel/PDF）
- 供应商 CRM 轻量化（联系方式、跟进记录）

## 结论

**Exhibo 是唯一的直接竞品**，但市场仍处于早期：
- AI 报告是他们的核心卖点（我们缺失）
- 精准标注 + 价格公式是我们的差异化（他们缺失或弱化）
- 两者都服务采购商（买方），与参展商（卖方）App 形成市场空白

**战略建议**：
1. 短期：深化标注体验 + 公式计算器（守住差异化）
2. 中期：补齐导出功能（Excel/PDF）
3. 长期：引入 AI 总结（但不作为核心，避免成本过高）
4. 定位：开源 + 自部署 + 中国市场优化（与 Exhibo 闭源商业化形成区隔）
