## 产品定位

**Slogan**: "Trade show intelligence for serious teams"  
**核心价值**: 买方采购/销售团队的展会全流程工具（展前规划 → 展中记录 → 展后报告）

**目标用户**:
- 采购团队（买方）
- 销售团队（买方）
- 多人协作团队
- 需要结构化报告的企业用户

## 核心功能

### 1. 展前规划（Pre-show Planning）
- **展会搜索**: 1,142+ 展会数据库，按行业/国家/日期搜索
- **参展商筛选**: 按类别过滤参展商
- **拜访清单**: 构建目标展位列表
- **团队分工**: 团队成员共享计划，分配展位

### 2. 展中记录（Floor Workflow）
- **语音听写**: 在展位现场快速记录笔记（核心差异化）
- **拍照功能**: 产品照片采集
- **标记跟进**: 标记需要后续跟进的供应商
- **离线同步**: PWA 应用，弱网/离线环境本地缓存

### 3. 展后报告（Post-show Reports）
- **自动生成**: 展会结束一周后自动生成总结报告
- **内容包含**: 联系人信息 + 笔记 + 照片链接
- **格式**: PDF 导出

### 4. 团队协作
- 共享拜访计划
- 展位分工
- 笔记汇总
- PWA 移动应用（跨平台）

## 优劣势分析

### ExpoFlow 的优势（我们缺失的）

1. **展会数据库** - 1,142+ 展会，内置参展商列表（巨大优势）
2. **语音听写** - 现场快速记录（比手动输入快 10 倍）
3. **展前规划** - 帮用户筛选要拜访的展位（省时间）
4. **自动报告** - 展后一周自动生成 PDF（省人工）
5. **定价清晰** - $9.99/展会（已验证商业模式）
6. **离线支持** - PWA 本地缓存（展馆信号差时有用）

### ExpoFlow 的劣势（我们的机会）

1. **标注不精准** - 只能附加照片到供应商，无法标注产品位置
2. **无价格功能** - 没有价格转换/计算器（采购核心需求）
3. **中国市场弱** - 未提及网络优化（广交会等场景）
4. **AI 成本** - 虽然用 Deepseek（便宜），但要额外收费 $5
5. **数据孤岛** - 依赖他们的展会数据库（用户无法自建展会）

### 我们的差异化机会

**核心优势**:
1. **精准标注** - 十字准星定位产品（ExpoFlow 做不到）
2. **价格公式** - 实时计算 FOB/CIF/USD/RMB（采购刚需）
3. **中国市场** - 网络稳定性 + 本地化（广交会/义乌展）
4. **灵活性** - 用户自建展会，不依赖第三方数据库

**需要补强**:
1. **导出功能** - Excel/PDF 导出（竞品标配）
2. **离线支持** - Service Worker 缓存关键数据
3. **展前规划** - 简单的拜访清单功能（可选）

**不做（明确排除）**:
- ❌ **语音输入** - 这是操作系统/输入法的职责，无需重复建设
- ❌ **AI 报告** - 成本高且不稳定，以后可外接第三方服务
