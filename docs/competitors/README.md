# 竞品研究

## 研究样本

### 直接竞品（为采购商设计）

1. **[Exhibo](exhibo.md)** - AI-Powered Trade Show Assistant
   - 状态：Active (iOS)
   - 核心：AI 报告生成 + 团队协作
   - 差异：我们强于精准标注 + 价格公式，他们强于 AI 分析 + 数据导出

## 市场空白

**发现**：展会 App 市场非常成熟，但几乎全部服务于**参展商（卖方）**。

**为采购商（买方）设计的 App 极其稀少**：
- Exhibo 是唯一找到的同类产品
- 大部分采购团队仍在用通用工具拼凑解决方案

**机会**：
- B2B 采购团队（批发商、连锁店采购、贸易公司）
- 中国市场（广交会、义乌展等高频场景）
- 垂直细分（服装/家居/电子等特定行业的采购 SOP）

---

## 研究方法

1. **功能对比** - 列出竞品的核心功能和我们的差异
2. **定价分析** - 推测商业模式和定价策略
3. **用户反馈** - App Store/Google Play 评论分析
4. **技术栈** - 推测技术选型和架构设计
5. **市场定位** - 目标用户和使用场景
