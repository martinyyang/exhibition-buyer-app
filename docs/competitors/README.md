# 竞品研究

本目录收录展会采购 App 的竞品分析，帮助我们理解市场定位和差异化机会。

---

## 研究样本

### 直接竞品（为采购商设计）

1. **[ExpoFlow](expoflow.md)** - Trade Show Intelligence Platform 🔥🔥🔥
   - 状态：Active，产品已上线运营
   - 定价：$9.99/展会（+$5 AI 功能）
   - 核心：展会数据库 (1,142+) + 语音听写 + 自动报告
   - 差异：他们强于展前规划 + 语音输入 + 自动报告，我们强于精准标注 + 价格公式
   - **最强竞品，需要重点关注**

2. **[Exhibo](exhibo.md)** - AI-Powered Trade Show Assistant
   - 状态：网站在线，但 App Store 找不到（可能内测）
   - 定价：未公开
   - 核心：AI 报告生成 + 团队协作
   - 差异：我们强于精准标注 + 价格公式，他们强于 AI 分析（如果真的上线）

3. **[ExpoRadar](exporadar.md)** - Pre-show Intelligence Platform
   - 状态：Active，展前分析工具
   - 定价：$199/展会（高价值）
   - 核心：AI 匹配参展商 + 决策者信息 + 公司情报
   - 关系：互补而非竞争（展前规划 vs 展中记录）

## 市场空白与机会

**发现**：展会 App 市场非常成熟，但几乎全部服务于**参展商（卖方）**。

**为采购商（买方）设计的 App 极其稀少**：
- ExpoFlow 是最成熟的产品（已上线，定价清晰）
- Exhibo 的 App 找不到（可能还在 MVP 阶段）
- ExpoRadar 专注展前（互补而非竞争）
- 大部分采购团队仍在用通用工具拼凑解决方案

**关键洞察**：
- 买方工具市场处于**早期阶段**（所有产品都没有用户评价）
- ExpoFlow 定价 $9.99/展会证明**用户愿意付费**
- ExpoRadar 定价 $199/展会证明**展前规划高价值**
- 展会数据库是巨大壁垒（ExpoFlow 有 1,142+ 展会）

**我们的机会**：
- **差异化功能**：精准标注 + 价格公式计算器（ExpoFlow 做不到）
- **中国市场**：网络优化 + 本地化（广交会、义乌展等高频场景）
- **垂直细分**：服装/家居/电子等特定行业的采购 SOP
- **开源路线**：开源核心代码 + 自部署（区别于 ExpoFlow 闭源）
- **低价策略**：$5-9.99/展会（无展会数据库成本，可以更便宜）

## 研究方法

1. **功能对比** - 列出竞品的核心功能和我们的差异
2. **定价分析** - 推测商业模式和定价策略
3. **用户反馈** - App Store/Google Play 评论分析
4. **技术栈** - 推测技术选型和架构设计
5. **市场定位** - 目标用户和使用场景
