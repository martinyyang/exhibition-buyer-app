## 2. 核心功能测试

### 2.1 用户认证
- [ ] **用户注册功能正常**
  - 输入邮箱和密码
  - 提交注册
  - 收到验证邮件（如有）
  - 注册成功

- [ ] **用户登录功能正常**
  - 输入正确的邮箱和密码
  - 点击登录
  - 登录成功，进入场次选择页面

- [ ] **登录错误处理正确**
  - 输入错误密码
  - 显示错误提示："邮箱或密码错误"
  - 输入空邮箱或密码
  - 显示验证提示

- [ ] **退出登录功能正常**
  - 点击右上角设置图标
  - 点击"退出登录"
  - 返回登录页面
  - 再次打开应用需重新登录

### 2.2 场次管理
- [ ] **创建场次成功**
  - 点击"创建场次"按钮
  - 输入场次名称（如"2026春季广交会"）
  - 选择开始日期
  - 点击保存
  - 场次显示在列表中

- [ ] **切换场次正常**
  - 创建两个场次
  - 点击第一个场次，验证进入该场次
  - 返回，点击第二个场次
  - 验证数据隔离正确（不显示第一个场次的摊位）

- [ ] **场次列表显示正确**
  - 显示所有创建的场次
  - 活跃场次显示✓标记
  - 显示场次创建日期

### 2.3 摊位管理
- [ ] **创建摊位成功**
  - 进入场次
  - 点击"创建摊位"按钮
  - 输入摊位号（如"B01"）
  - 点击保存
  - 摊位显示在列表中

- [ ] **摊位列表显示正确**
  - 显示所有摊位
  - 显示摊位号
  - 点击摊位进入照片列表

### 2.4 照片拍摄与上传
- [ ] **拍照功能正常**
  - 点击相机按钮
  - 调用系统相机
  - 拍摄照片
  - 照片显示在网格中

- [ ] **从相册选择照片正常**
  - 点击相机按钮
  - 选择"从相册选择"
  - 选择照片
  - 照片显示在网格中

- [ ] **照片上传成功**
  - 拍摄或选择照片
  - 显示上传进度（如有）
  - 照片上传到云端
  - 其他用户能看到照片

- [ ] **照片压缩正常**
  - 拍摄高分辨率照片
  - 验证照片被压缩（文件大小合理）
  - 照片质量仍清晰可辨

### 2.5 旗子标注功能
- [ ] **插旗功能正常**
  - 点击照片进入详情页
  - 在照片上点击位置
  - 十字准星中心点精确对齐到点击位置（基于图片显示区域的1.5%网格吸附）
  - 旗子编号自动递增（1, 2, 3...）
  - 注意：旗子形状为十字准星（40x40 px），中心点在(20, 20)，定位偏移为left: -20, top: -20

- [ ] **旗子表格显示正确**
  - 右侧显示旗子表格
  - 每个旗子一行
  - 显示旗子编号、报价、目标价

- [ ] **填写报价功能正常**
  - 在"报价(RMB)"列输入价格（如"1000"）
  - 按回车或点击其他位置
  - 换算价格自动计算并显示

- [ ] **换算价格计算正确**
  - 输入报价：1000元
  - 验证换算价格（如 1000 * 0.14 = 140.00）
  - 输入其他报价，验证计算正确

- [ ] **设置目标价功能正常**
  - 在"目标价"列输入目标价格（如"120"）
  - 按回车或点击其他位置
  - 目标价保存成功

- [ ] **红色警告标记显示正确**
  - 设置目标价低于换算价格
  - 验证显示🚨标记
  - 更新报价使换算价格低于目标价
  - 验证🚨标记消失

### 2.6 实时同步
- [ ] **双端实时同步正常**
  - 使用两个设备（或买手端+Web端）
  - 在买手端插旗
  - 验证远程端实时看到旗子（延迟 < 2秒）
  - 在远程端修改目标价
  - 验证买手端实时看到更新

- [ ] **多用户协作正常**
  - 使用两个买手账号
  - 买手A拍照
  - 验证买手B能看到买手A的照片
  - 验证颜色标识不同
